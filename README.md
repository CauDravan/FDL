# Project: CD Archievements

## Overview
This is a personal website that tracks all the games and levels I've completed (cleared). The site helps me keep a record of my gaming achievements over time.

## Tech Stack
- **HTML5** - Page structure
- **Tailwind CSS** - Styling
- **JavaScript** - Logic and interactivity
- **Vite** - Build tool

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open your browser and navigate to `http://localhost:5173` to view the website.

## Folder Structure
```
├── index.html          # Main page displaying game list
├── details.html        # Detailed view for each game
├── src/
│   ├── assets/         # Images and icons
│   ├── data/           # Game data (JSON)
│   ├── scripts/        # JavaScript logic
│   └── styles/         # CSS and animations
├── tailwind.config.js  # Tailwind configuration
└── vite.config.js      # Vite configuration
```

## Features
- Display list of cleared games
- Search and filter by genre, platform
- Overall achievement statistics
- Responsive design for all devices
